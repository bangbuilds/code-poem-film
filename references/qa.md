# 检查与调试

## 三个命令各查什么

```bash
python3 tools/film.py qa        # 画场景时反复跑，约 40 秒
python3 tools/film.py score     # 改了编曲或换了配音后跑，看打印的自检
python3 tools/film.py render    # 出片；渲染后自动核对成片
```

### qa

1. **工程检查**（HyperFrames 的 lint / runtime / layout）。有错先改错。
2. **时间表**：两句朗诵有没有重叠；最后一句题签有没有压到末句；题签是不是在句子念完前就撤了；末句每个字的时刻是不是递增；红点从场景跳到第一笔的时间够不够（至少 0.4 秒）。
3. **抓帧**：时间表里每个有名字的时刻、每句朗诵的中段、末句隔一个字、结尾，各抓一帧，自动查：

| 报告 | 意思 | 常见原因 |
|---|---|---|
| this frame threw an error | 这一帧的代码抛了异常，错误信息用红底写在画面顶上 | 用了没有笔画数据的字（加进 `poem.json` 的 `glyphs`）；变量名写错；`t < 0` 时除了零 |
| the frame is almost empty paper | 该有场景的时候几乎是白纸 | 透明度写成了 0；镜头跑出了世界的范围；图层画在了画面外 |
| the red dot is not in the frame | 主角不在画面里或被挡住 | 被前景盖住；位置算到了画面外；远景里画得太小（半径别小于 18） |
| a lot of red on screen | 红色面积太大 | 别的东西用了朱红。换成藤黄、胭脂、赭石 |
| nothing changed between these frames | 相隔半秒以上的两帧一模一样 | 这一段没有戏；或者某个动画用错了时间变量 |

4. **总览图** `build/qa/contact-N.jpg`：每格左上角是成片里的时刻和事件名。**一定要打开看**。脚本看不出来的：

- 东西悬在半空或陷进山里（贴图偏移算错）。
- 前景太糊、太大，像一块污渍。
- 字压在主体上，或者主体在题签后面。
- 构图空：一大片没东西。
- 红点太小、和暖色背景混在一起。
- 淡出的场景里有东西压到落款、印章、片尾小字。
- 图层在右端露出硬边（贴图没铺满，或者雾气用矩形画了、有台阶）。

单独看某一刻：`npx hyperframes snapshot --no-end --describe false --at 12.4,12.6`，图在 `snapshots/`。看细节时直接打开那张 1920×1080 的 PNG，别只看总览图。

### render 之后的核对

| 核对 | 不通过时 |
|---|---|
| 帧数 = 总时长 × 帧率 | 重新跑 `film.py timing`（`index.html` 里的时长没更新）。多出 1 帧是时长四舍五入进位造成的，`timing` 现在向下截断 |
| 响度约 −16 LUFS | 重新跑 `film.py score` |
| 每段朗诵的位置和计划相差不到 30 毫秒 | `score` 之后又改了时间表：重跑 `film.py build` 再渲染 |
| 中间没有超过半秒的静止画面 | 看那一段是不是有意的停顿 |
| 第一帧不是白纸 | 给片子画封面（`cover`） |

结果写在 `build/package.json` 的 `problems` 里。

## 翻过的车

| 现象 | 原因 | 现在怎么防 |
|---|---|---|
| 猿挂的树悬在半空 | 「画面 x → 贴图 x」的偏移加错了 | `scenes.md` 里的换算；看总览图 |
| 前景礁石像一团污渍 | 横向拖影太重、石头太高 | `SC.bankTile` 的 `smear` 不超过 3，高度别超过画面的四分之一 |
| 远山右端有一级级台阶 | 山脚的雾用矩形画，在山结束的地方露了边 | 雾画进贴图里（`fadingRidge` 已经这样做） |
| 印章下面那个字被切掉一半 | 印文位置按固定像素排 | `A.seal` 现在按印章尺寸排 |
| 淡出的小舟压在片尾小字上 | 没看最后一帧 | 结尾那一格也在总览图里；`scenes.md` 写了落款占的位置 |
| 缩略图是一张白纸 | 片子从白纸开始 | 封面是第一帧；`render` 会查第一帧 |
| 画面卡住不动、没有报错 | 某一帧抛了异常，画布停在上一帧 | 舞台把错误写在画面上，`qa` 会报 |
| 鼓把旋律盖住 | 低频占了一半以上能量，而没人听过 | `score` 打印每段频段占比 |
| 多音字可能念错 | 听不到，查不出来 | `poem.json` 的 `say` 用同音字 |
| 两句之间的逗号没有停顿，切不开 | 语音把一联连读了 | 切段找「最深的低谷」而不是「静音」；还不行就把 `punct` 改成句号 |
| 笔和声音错开 | 末句每个字的时刻是平均分的 | `voice --spec` 看频谱图标 `onsets` |
| 换了音色后画面和声音对不上 | 只重跑了配音，没重跑时间表和混音 | `film.py voice` 会自动跑 `timing`；之后再跑 `film.py build` |
| 小舟像搁在礁石上 | 小舟的水线比礁石的水线高（更远），却画在礁石之后 | 水面上的东西按水线排前后，见 `scenes.md` |
| 山崖像一块木板 | 岩面全是从上到下的细长竖线 | 色块、横向岩层、折线裂缝，见 `scenes.md` |
| 镜头仰起时山脚和岸之间露出一条白纸 | 远层没有跟着镜头的俯仰走 | 远层也乘一个 `cam.up` 的系数 |
| 该到那一句才出现的东西，一开场就露在题签后面 | 它在岸上的位置离起点太近 | 让那一句之前多走一段（加长那一句的停顿），或把它往后挪 |
| 成片比预期多 1 帧 | 页面里的时长写成 72.1667，渲染器向上取整 | `dump_timing` 改成向下截断 |
| 长片的上传版糊成一片 | 72 秒硬压到 10 MB 以内 | `render` 对长片保留一个高画质 1080p，另出 720p 小版 |
| 朗诵听起来在「念」 | 语音每秒读 3.5–4 个字 | `voice.tempo` 本地放慢，见 `audio.md` |

## 浏览器预览

`npx hyperframes preview` 可以在浏览器里播放、拖时间轴、听声音。几个坑：

- 改了 `engine/`、`film/`、`assets/` 里的 js 之后要刷新页面；贴图是加载时画的，不刷新看不到变化。
- 预览里播放的声音就是 `assets/score.wav`，改了编曲要先 `film.py score`。
- 在预览页的控制台里：`FILM.draw(12.4)` 画某一刻，`FILM.error` 是最近一帧的错误，`FILM.debug` 是场景文件挂出来的数（镜头位置、角色位置），`TIMING` 是时间表。
- 预览服务器会在 `index.html` 里加 `data-hf-id` 属性，属于正常。

## 性能

`FILM.draw` 每帧应该在几毫秒以内。慢了通常是：每帧在画本该进贴图的大量细节；每帧新建 canvas；`ctx.filter` 或大半径 `shadowBlur` 用在了每帧都画的大面积上（只在转场的几帧里用可以）。
