# 红点怎么演

这类片子好不好看，七成在红点的戏。它没有手脚，只有形状、位置、眼睛，所以每一样都要用上。

## 它是谁

红点就是诗里的「我」。诗人辞别白帝城，它就在城楼前鞠躬告别；诗人坐船，它就坐在船里。所以分镜先回答一个问题：**这句诗里「我」在哪、在干什么、看见了什么**。答不出来的句子（纯写景），就让它当观众：停下来、转头看、睁大眼。

一条片子里它的弧线通常是：落到纸上 → 发现世界 → 上路 → 遇到点什么 → 豁然开朗 → 提笔把最后一句写出来 → 变成印章。

## 身体

`A.dot(ctx, x, y, { r, sx, sy, rot, … })`，`sx` / `sy` 是横竖方向的拉伸。体积要守恒：一个方向变大，另一个方向就变小。

| 时刻 | 形状 |
|---|---|
| 下落、起跳、飞行 | 沿运动方向拉长：`sy 1.2–1.3, sx 0.8` |
| 落地 | 压扁再弹回：`sx 1.5, sy 0.55`，0.12 秒 |
| 起跳前 | 先蹲（蓄力）：`sy 0.6, sx 1.34`，0.15–0.2 秒，再弹出去 |
| 停住之后 | 抖两下再静止：`QZ.decay(t, t0, 8, 24) * 0.06` |

站在地面上的运动用 `A.mover`，一条链写完整段：

```js
const s = { x: 0, y: -R, sx: 1, sy: 1, rot: 0, air: 0 };
const m = A.mover(t, s, R);
if (m.dropIn(T, T.bow1)) {                       // 标准入场：落下、弹两下、站稳
} else if (m.hop(T.bow1, 0.24, 46)) {            // 原地跳一下（时刻、时长、高度）
} else if (m.squash(T.bow1 + 0.24, 0.07, 0.3)) { // 落地压一下
} else if (m.hop(T.roll, 0.2, 40, 0, 104)) {     // 边跳边往前（x 从 0 到 104）
} else { … }
```

三条经验：

- **动作之前先有反方向的预备**。要往右冲，先往左缩一下；要跳，先蹲。没有预备的动作像被线拽走的。
- **重的落地要有后果**：墨点炸开（`A.ticks`）、镜头抖一下（`QZ.decay`）、船往下沉再浮起来、水花（`A.splash`）。
- **别让它闲着超过一秒**。站着的时候眨眼、转眼珠、轻轻呼吸（`sy` 上下 2%）。

## 眼睛

`eye`（0→1，眼睛弹出来）、`open`（0 闭 … 1 睁）、`lx` / `ly`（−1…1，看向哪）、`mood`。

| mood | 什么时候用 |
|---|---|
| `plain` | 平常 |
| `happy`（^ ^） | 上路、得意、盖章之后 |
| `wow`（睁大 + 小圆嘴） | 世界晕开、看见新东西、失重 |
| `set`（压着眉毛） | 蓄力、冲刺、写字 |
| `squint`（> <） | 撞击、落水的那一瞬 |

- 眼睛比身体先动。要转向之前 0.1–0.2 秒先看过去。
- 每句诗开头让它看一眼这句写的东西（猿、楼、月亮），观众的视线会跟过去。
- 眨眼 0.15 秒，两三秒一次，别规律得像节拍器。
- 入场时先是一个没有眼睛的点，站稳后眼睛「啵」地弹出来（`ease.outBack`），这是它活过来的一刻，留给它半秒安静。

表情按时间写成一个函数，范例里是 `face(t)`：先给默认值，再按时间段覆盖。

## 和朗诵对位

对位写在 `film/timing.js` 里，是算出来的，不是凑出来的。

- **事件落在换气里**：`{ gapAt: T.launch }`。「千里江陵——（弹射）——一日还」。鼓点和冲出去的声音正好填在停顿里，两边都清楚。
- **叫到名字的东西此刻在场**：念「猿声」时猿正在叫，念「孤帆」时帆正好出画。先定这句从哪一刻念（`at`），再把那个东西安排在那一刻出现在好看的位置（范例里猿的位置是按「它叫的那一刻镜头在哪」反推出来的）。
- **留一段不说话**：最后一句之前给两三秒只有画面和音乐的时间（范例的万重山远景）。前面一直有人声，这里安静下来，最后一句才有分量。
- **末句边念边写**：舞台已经做了。你要做的是把每个字的时刻标准（`audio.md`）。

## 节奏

一句七言念下来约 2–3 秒，所以每句诗的戏也就 3 秒左右，只够一个动作加一个反应。别塞两件事。

全片有快有慢才有呼吸：范例是「慢（落下、睁眼）→ 中（告别、起跳）→ 快（穿峡）→ 很慢（远景）→ 写字 → 盖章停住」。四句都一个速度会很平。

## 自查

看 `film.py qa` 的总览图时问自己：

- 每一格里一眼能找到红点吗？（太小、被挡住、和背景的暖色混在一起，都算找不到。）
- 它在看哪？和这一句有关系吗？
- 这一格和上一格相比，它的形状变了吗？一直是正圆说明戏太少。
- 关掉声音，只看这几格，能不能看懂这首诗在讲什么？
