# 声音：朗诵、配乐、混音

## 朗诵

```bash
python3 tools/film.py voice --dry     # 不合成：按每秒 2.6 字估时长，片子里没有人声。排场景用这个，不花钱
python3 tools/film.py voice --plan    # 只列出真配音会合成哪几段、各多少字、哪些已有缓存。花钱之前先跑这个
python3 tools/film.py voice           # 真配音，切成 标题 / 作者 / 每一句
python3 tools/film.py voice --spec    # 同上，另外画出每句的频谱图 build/spec/l1…lN.png
python3 tools/film.py voice --provider say            # 临时换一个语音试试，不改 poem.json
python3 tools/film.py voice --id <音色> --speed 0.85
```

短诗（8 句以内）整首在**一次调用**里合成（标题。作者。四句），句与句之间的语气是连贯的；然后按标点处的停顿切开，每一段单独放到画面对应的时刻。

长篇（超过 8 句，或 `voice.split: "sentence"`）**逐句合成**：标题和作者一段，之后每到句号、叹号、问号、分号为一段，段内再按逗号切。原因是从一段一分钟的录音里靠停顿切出二十几个短句不可靠，而切错了你听不出来。赤壁怀古是 9 段、109 个字。

同一个「语音 + 音色 + 语速 + 文字」只合成一次，结果缓存在 `audio/tts/`，重跑不花钱；改了某一句只重新合成它所在的那一段。

**读得太快怎么办**：先看 `voice` 打印的每句「字/秒」。超过 3.3 的句子可以在本地放慢，不重新合成、不花钱：

```json
"voice": { "tempo": { "*": 0.92, "l4": 0.82, "l22": 0.84 } }
```

`"*"` 是所有诗句（不含标题和作者），单独写的句子优先。放慢用的是变速不变调，0.85 以上基本听不出来，别低于 0.8。改完重跑 `film.py voice`（走缓存），画面按新长度重排，`onsets` 里的数不用改（它们按原速标，引擎会换算）。

`poem.json` 的 `voice.provider`：

| 值 | 是什么 |
|---|---|
| `auto` | 装了 `edge-tts` 就用它，否则在 macOS 上用系统自带的 `say`。免费，机器味重，用来验证流程够了 |
| `say` / `edge` | 指定其中一个 |
| `command` | 任意命令行：`"command": "mytts --out {out} \"{text}\""` |
| 你自己的名字 | 在 `~/.config/code-poem-film/` 放一个 `tts_<名字>.py`，实现 `synth(text, voice, out_path)`。按次付费的云端声音和它的密钥放在这里，不要放进工程（`~/.config/code-doc-film/` 里的插件也能被找到） |

这台机器常用的音色可以写在 `~/.config/code-poem-film/defaults.json`（`{"voice": {...}}`），新建工程时自动填进 `poem.json`。

**花钱的规矩**：真配音之前，题材和诗句要已经定了（改一个字就得重新合成）。按次付费的语音，动手前告诉用户「会调用几次、每次多少字」。试几个音色就是几次调用。

切段失败（报「找不到某一段后面的停顿」）通常是读得太快、句间没停。办法：把语速降到 0.8，或者把 `punct` 全改成句号。

`voice` 打印的表要看一眼：

```
piece      from     to    len    字/秒  pauses inside
l1         3.89   6.12   2.23   3.15  []
l2         6.70   9.54   2.85   2.46  [[1.42, 1.78], [2.42, 2.53]]
```

- 每句 2–3 秒、每秒 2.4–3.2 字，是朗诵的速度。到 4 字/秒就是在「念」，不是在「诵」。
- `pauses inside` 是句子内部的停顿（从这句开头算的秒数）。句中间那个长的停顿就是换气，`gapAt` 用的就是它。

## 多音字

合成引擎可能把「还」念成 hái、「朝」念成 cháo、「重」念成 zhòng，而你听不出来。办法是在送去合成的文字里把它换成**只有一个读音的同音字**：

```json
"say": { "朝": "昭", "还": "环", "重": "崇" }
```

画面上写的永远是原字。开工时把整首诗过一遍，凡是有两个读音的字都处理掉。常见的：

| 字 | 诗里的读音 | 可以换成 |
|---|---|---|
| 朝（早晨） | zhāo | 昭 |
| 还（归来） | huán | 环 |
| 重（一层层） | chóng | 崇 |
| 长（生长） | zhǎng | 掌 |
| 乐（音乐） | yuè | 月 |
| 少（年少） | shào | 哨 |

替换用的字本身必须只有一个读音，拿不准就查字典。押韵的旧读（斜、骑、衰、回这类）按现行教材的读法来，不要自作主张改古音；用户有要求再改。同一个字在诗里出现两次、读音不同，用 `sayLines` 整句替换。

## 选音色

多数语音服务只能选音色和语速，没有「感情」这个参数，所以「有感情的朗诵」靠选对音色。你听不到，能比较的只有量出来的东西：

- **语速**：每秒 2.4–3.2 字像朗诵。
- **停顿**：句与句之间停 0.5 秒以上；七言句内部在第 4 字后有换气。
- **收句放慢**：每联的下句（第 2、4 句）比上句长，是朗诵的特征。
- **轻重变化**：`voice` 最后打印的 loud-to-soft spread，平铺直叙约 12 分贝，抑扬顿挫的 16 分贝以上。

按这些挑一个默认的，再出一版别的音色让用户对比。换音色只要重跑 `voice`、`build`、`render --out <名字>`，画面会按新音色的长度自动重排。在帖子和汇报里只说「按停顿和轻重变化挑的」，不要说「更有感情」。

## 末句逐字对时

最后一句是边念边写的，每个字什么时候开始念要告诉引擎：

```json
"onsets": { "<音色 id>": [0.0, 0.46, 1.01, 1.17, 1.67, 2.02, 2.5] }
```

数字是从这一句开头算的秒数，个数等于这一句的字数。没有这一项时按平均分，`voice` 会提醒你。

办法是读频谱图：`python3 tools/film.py voice --spec`，然后打开 `build/spec/l<最后一句>.png`。横轴是时间（每 0.1 秒一个刻度，标尺的 0 比这一句的开头早 0.05 秒，所以读出来的数要减 0.05），纵轴是频率。

| 图上的样子 | 是什么 |
|---|---|
| 一叠横向的亮条纹 | 元音（一个字的主体） |
| 从下到上一整根「雪花柱」 | q、zh、ch、sh、s、x、c 这类擦音，是一个字的开头 |
| 一小段全黑 | b、d、g、p、t、k 发音前的闭塞，或者停顿 |
| 亮条纹整体往上或往下斜 | 声调在变（二声上扬、四声下降） |
| 只在最底下有一条亮带 | 鼻音、ong、un 这类，能量低，容易被当成停顿 |

做法：先数出明显的停顿把这一句分成几截（七言通常是 2 + 2 + 3），再在每一截里按擦音柱和闭塞找字的开头。标到 ±0.05 秒就够了，笔比声音晚几十毫秒看不出来。标完跑 `film.py voice`（有缓存，不花钱），`timing` 会打印每个字的时刻。

## 配乐

`film/score.py` 用 `tools/synth.py` 里的乐器，往四条总线上放声音，时刻都从 `build/timing.json`（`T[...]`）里取：

```python
from synth import *
music.add(pluck('D4', 1.8, 0.6), T['bloom'], 0.5, pan=-0.3)   # (声音, 影片时钟的时刻, 音量, 声像 -1…1)
lead.add(flute([(0, 0.5, 'A5'), (0.5, 1.0, 'D6')]), T['cut'])
fx.add(splash(1.0), T['boatLand'])
finish([('A', 0, T['bloom']), ('B', T['bloom'], T['hop']), …])     # 混音、写文件、打印自检
```

| 总线 | 放什么 | 人声出现时 |
|---|---|---|
| `music` | 拨弦、铺底、鼓 | 压低约 9 分贝 |
| `lead` | 笛子（旋律） | 几乎退出，人声停了再回来 |
| `fx` | 音效（和 `music` 一起算作背景） | 压低约 9 分贝 |
| `voice` | 朗诵，`finish` 自动放 | — |

乐器：

| 函数 | 声音 |
|---|---|
| `pluck(音名, 时长, 亮度)` | 拨弦（古筝感），主力 |
| `flute([(开始, 时长, 音名), …], legato, vib)` | 竹笛，一个乐句一次调用，音与音之间会滑 |
| `pad([音名…], 时长, 起音, 收音, 亮度)` | 弦乐铺底 |
| `tanggu(力度, 音高)`、`woodblock(力度, 音高)`、`gong(频率, 时长, 力度)` | 堂鼓、木鱼、锣 |
| `glide(f0, f1, 时长, 谐波, vib, shape)` | 滑音：下落的哨音、起跳的「嗖」 |
| `whoosh(时长, f0, f1, 力度)`、`splash(力度)`、`hoot(基频)`、`noise(n, lo, hi)` | 风声/冲刺、水花、猿啼、带通噪声（水声、笔触） |
| `horn([(开始, 时长, 音名), …], 力度)` | 号角：隔着水面传来的长音 |
| `dagu(力度)`、`roll(时长, 力度, 起速, 止速)` | 大鼓（比堂鼓低而长）；越打越密的滚奏，接在大事件前面 |
| `tremolo(音名, 时长, 每秒几下)` | 轮指：一根弦上急促的连拨，制造紧张 |
| `crackle(时长, 力度)`、`water(时长, 力度, lo, hi, rate)` | 火的低吼和噼啪；流水 |
| `scale('D')` | 以某个音为宫的五声音阶，从低到高的音名表。想苍凉一点就把旋律落在羽音上：`scale('G')` 的音以 E 为主音就是 E 羽调 |

编曲的做法：

- **全片一个调，只用五声音阶**（1 2 3 5 6）。怎么叠都不会难听，这对听不到声音的人很重要。
- **每个声音都绑在画面的一个时刻上**：落地一声鼓加一个拨弦，睁眼两声高音，世界晕开一串上行的刮奏，每个字一声弦，盖章一声鼓加一声锣。画面动了声音不响、或者声音响了画面没动，都会显得假。
- **快的段落定一个节拍**（范例：从弹射那一刻起每拍 0.38 秒），再把这一段的事件挪到拍子上，鼓和拨弦按拍走。拍长写进时间表（`beat`，并列入 `notEvents`）。
- **有人声的地方编得稀**：铺底加几个拨弦就够。笛子留给没人说话的段落。
- **有高点也要有空白**：全片最响的时刻只留一两处（弹射、盖章）。最后一句之前留一段只有铺底和笛子的安静。
- **大事件落在句子里时，把它压住**：「惊涛拍岸」的那一拍、「樯橹灰飞烟灭」的那场火，声音最想放大的地方恰好有人在念。先按想要的音量编，跑一遍自检，把 margin 低于 8 的那一句底下的鼓、锣、噪声降下来——字要听得见，气势靠句子前后的空档补。

## 混音和自检

`finish()` 做的事：给每条总线加一点混响；人声出现前 0.12 秒开始把背景压下去，人声停后 0.3 秒放回来；整体归一到 −16 LUFS（各平台通用的响度），留 1 分贝余量。

然后打印：

```
score.wav: 25.53s, -16.0 LUFS, peak -3.0 dBFS
  D      10.70–16.02s  rms  -17.6 dB   60–150Hz 18%  150–500 60%  500–2k 21%  2k–6k  2%
  voice over bed while speaking (aim for 9 dB or more):
    l2     at  9.24s  voice  -18.2 dB   bed  -27.3 dB   margin   9.1 dB
```

怎么看：

| 现象 | 说明 | 怎么办 |
|---|---|---|
| 某段 60–150Hz 超过 45% | 鼓和锣把能量占了，手机外放时旋律会显得很小 | 降 `tanggu` / `gong` 的音量，或者把它们的音高提高 |
| 某段 500–2k 超过 70% | 笛子太突出 | 降这一段 `lead` 的音量 |
| 人声 margin 低于 7 分贝 | 这一句被背景盖住 | 把这一句底下的东西编稀、降音量；或在 `poem.json` 的 `voice.lift` 里把这一段人声提一点（`{"l2": 1.3}`） |
| 各段 rms 差超过 8 分贝 | 忽大忽小 | 调各段的音量 |
| 人声各段的 voice dB 差 5 分贝以上 | 有的句子说得很轻 | `voice.lift`；不写这一项时会自动把轻的段落往前提一些 |

`build/score_report.json` 里有同样的数字。`film.py render` 还会核对成片里每段人声的位置是否和计划一致。

这些数字只能说明「没有明显的毛病」，说明不了「好听」。
