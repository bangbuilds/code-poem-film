# 范例：《念奴娇·赤壁怀古》

苏轼的词，一百个字、二十二句，成片 72 秒（封面 3.3 秒 + 正片 68.9 秒）。这是用 skill 做的第二条片子，也是长篇的做法范例：一条江、三个时辰（白天 → 入暮 → 月夜），镜头一直跟着小舟。

```bash
python3 $SK/scripts/new_project.py videos/chibi-demo --example chibi
cd videos/chibi-demo
python3 tools/film.py voice --plan          # 先看会合成几段（9 段）
python3 tools/film.py voice && python3 tools/film.py build && python3 tools/film.py qa
python3 tools/film.py render
```

## 值得照着学的做法

| 做法 | 在哪 |
|---|---|
| 长篇反过来排时间：先定每句之间停多久，动作挂在「第几句的哪个位置」上 | `timing.js` 的 `gaps`、`S[i] + d(i) * 0.6` |
| 逐句合成（9 段），每段内按逗号切开 | `poem.json` 句数超过 8 自动按句号分段；`film.py voice --plan` |
| 同一个字两种读音（英发 fā、华发 fà）用整句替换 | `poem.json` 的 `sayLines` |
| 读得偏快的句子本地放慢，不重新合成 | `poem.local.json` 的 `voice.tempo`（公开版用系统语音，没带这项） |
| 岸上的东西按「它被念到的那一刻该在屏幕哪」反推位置 | `scenes.js` 的 `lxAt()`、`fortLX`、`cliffLX`、`spireLX` |
| 镜头仰起时远山跟着多走一些，免得山和岸之间露出白纸 | `drawRiver()` 里各层的 `up * 0.4 / 0.55 / 0.78` |
| 把整帧画进一张画布，再缩成手卷里的一幅画 | `scene()` 里的 `props.pic` + `SC.scrollMount` |
| 人物画在浪里（裁剪在浪的形状内） | `heroWave()`，`A.bigWave` 的 `inside` |
| 同一个世界换时辰：日落、入暮的褐色、夜色都是盖在上面的一层 | `drawRiver()` 的 `sun` / `dusk` / `night` |
| 用浓烟盖住「白天 → 夜晚」的切换 | `vision()` 结尾的烟层和 `T.night` |
| 红点离开后，空舟淡出，落款下面不留东西 | `drawWorld()` 的 `skiffA` |
| 红点带着场景里得到的东西去写字（三根白发） | 交给舞台的 `decorate` |
| 人声在的地方把效果压低：巨浪拍岸、火烧连环船都在句子里 | `score.py` 里这两段的音量；自检的 margin |

## 关于声音

成片用的是作者自己的一个按次付费的云端男声，逐句合成共 9 次调用；读得偏快（每秒约 3.1 字），在本地放慢到约 2.9 字，没有重新合成。末句每个字的时刻是对着频谱图标的。这些设置在作者机器上的 `poem.local.json` 里，不随仓库公开。公开的范例默认用系统语音，画面会按实际读出来的长度重排。
