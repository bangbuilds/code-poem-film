# 范例：《早发白帝城》

李白的七言绝句，25.5 秒（封面 2.1 秒 + 正片 23.4 秒）。这个 skill 就是从这条片子里拆出来的。

```bash
python3 $SK/scripts/new_project.py videos/qingzhou-demo --example qingzhou
cd videos/qingzhou-demo
python3 tools/film.py voice && python3 tools/film.py build && python3 tools/film.py qa
python3 tools/film.py render
```

## 分镜

| 影片时钟 | 诗句 | 画面 | 红点 |
|---|---|---|---|
| 0–3.0 | — | 白纸 | 落下、弹两下、长出眼睛、左右看 |
| 3.0–5.9 | 朝辞白帝彩云间 | 白帝城和彩云从它脚下晕开 | 回头看城楼、跳两下告别、助跑、蓄力、跃下山崖 |
| 5.9–8.6 | 千里江陵｜ | 穿云下落，镜头跟到江面 | 落进小舟、升帆、往后一拉 |
| 8.6–10.0 | ｜一日还 | 小舟弹射出去 | 弹射正好落在朗诵换气的地方 |
| 10.0–13.5 | 两岸猿声啼不住 | 穿峡，三只猿依次啼叫，跃过急流 | 抬头看猿、腾空、落水 |
| 13.5–13.9 | — | 一面山崖扫过镜头（盖住切换） | |
| 13.9–17.2 | （不念） | 远景：层层山滑到身后，水面开阔 | 回头看一眼 |
| 17.2–20.7 | 轻舟已过万重山 | 场景淡到身后，大字逐笔写出 | 跳出小舟，沿笔画写，念到哪个字写到哪个字 |
| 20.7–23.4 | — | 落款、印章「太白」、片尾小字 | 跳到卷末，压扁成印章 |

## 值得照着学的做法

| 做法 | 在哪 |
|---|---|
| 一个连续的世界 + 一个会跟、会落后、会抖的镜头 | `scenes.js` 的 `camera()`、`sceneRiver()` |
| 四层视差（远峰 0.08、群山 0.22、对岸 0.5、前景 1.7） | `drawRiverWorld()` |
| 世界从红点脚下晕开 | `sceneRiver()` 里的 `ST.bloom` |
| 东西站在山脊上（猿的树）：先定「它叫的那一刻在屏幕哪」，反推世界坐标，再问贴图要山顶高度 | `placeGibbons()`、`cliffTopAt()` |
| 物体转场：山崖扫过整个画面时切到远景 | `gateWipe()`，放在 `front` 里 |
| 远景里几层山用不同速度滑走 | `sceneWide()`、`wideEnd()` |
| 船的速度写成关键帧，位置是速度的积分 | 文件开头的 `speedKeys`、`travel()` |
| 弹射落在朗诵的换气里 | `timing.js` 的 `{ gapAt: T.launch }` |
| 快的段落按 0.38 秒一拍编，事件都挪到拍子上 | `timing.js` 的 `beat`、`score.py` 的 D 段 |
| 腾空时鼓全部停掉，只留一点闪烁和上行的哨音 | `score.py` 里 `air = (10, 12)` |

## 关于声音

成片用的是作者自己的一个按次付费的云端男声，末句每个字的时刻是对着频谱图手标的；这些设置留在作者机器上，不随仓库公开。公开的范例默认用系统语音：画面会按实际读出来的长度重排（系统语音读得快，句中没有换气，第二句就按 `at: 7.2` 开始），末句的笔画按平均分。
